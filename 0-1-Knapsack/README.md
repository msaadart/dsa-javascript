----------0/1 Knapsack

What is 0/1 Knapsack:
Knapsack: Bag. 
0/1: Take or Skip.
Imagine hmare pas ek bag hai jiska weight limit hai.
Example:
Bag sirf 10Kg carry krskta hai and we have some items:
Item	Weight	Profit
Gold	3kg	50
Laptop	4kg	70
Camera	5kg	90

Task is: Konse items bag mai daalein taa k maximum profit mile without limit exceed kiye.
Rule is: Kisi bhi item ko half nhi kt skte.

What is the purpose:
Limited resources mai maximum benefit nikalna.
•	limited weight 
•	limited time 
•	limited money 
•	limited memory
